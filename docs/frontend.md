# Frontend

O frontend usa React, TypeScript, Vite e Tailwind.

Direção visual:

- Preto profundo.
- Branco pérola.
- Rose gold e dourado como acentos.
- Verde orgânico discreto vindo das fotos de referência.
- Tipografia editorial com Cormorant Garamond.
- UI técnica com Inter e Montserrat.

Rotas públicas:

- `/`
- `/servicos`
- `/precos`
- `/tabela-de-tamanhos`
- `/galeria`
- `/sobre`
- `/localizacao`
- `/politica-de-privacidade`

Componentes de alto impacto:

- Hero institucional.
- Catálogo de serviços.
- Tabela de comprimento.
- Calculadora com manequim digital.
- Laboratório de produtos.
- Galeria.
- CTA de localização e WhatsApp.
