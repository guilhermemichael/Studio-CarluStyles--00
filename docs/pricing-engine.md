# Motor de Preços

Modos:

- `fixed`: preço fixo.
- `by_length`: preço por comprimento.
- `evaluation`: sob avaliação.
- `range`: faixa de preço.

Comprimentos:

- `short`: Curto.
- `medium`: Médio.
- `long`: Longo.
- `extra_long`: Extra longo.

O `ServicePricePresenter` converte registros relacionais em contrato de API pronto para o frontend.
